## 2. КРАСНЫЕ ЛИНИИ — делать НЕЛЬЗЯ

### 2.1 Отклонено осознанно — не предлагать и не выполнять

1. **Делегирование событий (один слушатель на `#app` + `data-act` вместо ~90 привязок).**
   Запрещено: клик-тесты (`tests/click.test.js`) покрывают лишь 6 сценариев — для ~200+
   точечных правок (и обработчики, и шаблоны) этого недостаточно. Перед любой попыткой
   сначала расширить клик-тесты под все затрагиваемые сценарии. Без этого — слепой риск
   ради косметики; текущие секции `attach*Handlers` и id-тест уже дают достаточную
   читаемость и защиту.

2. **Консолидация UI-флагов в объекты `ui` / `authUi` (18 `let *Open/*Busy/*Msg/*Error`).**
   Запрещено: тех же 6 клик-тестов мало для rename в ~147 местах; массовый rename молча
   ломает чувствительность тестов панелей (vm-тест с `aboutPanelOpen = true` станет
   бессмысленным). Выгода — только косметическая.

3. **Массовая замена boilerplate «getElementById + if + addEventListener» на `on()`.**
   Ограничить: `on()` применяется только при переписывании конкретной секции по другой
   причине. Не начинать отдельную «чистку» — риск сломать рабочие обработчики ради
   косметики (п. 1 — тот же аргумент).

### 2.2 Запреты проекта (из AGENTS.md — не нарушать)

- Не разносить код на отдельные `.js`/`.css`-файлы (ломает `sw.js ASSETS`, `tests/helpers.js`, философию «один статический файл»).
- Не добавлять зависимости, фреймворки, сборку, ESLint.
- Не трогать формулы колеса, липкую механику `totalGoalsAdded`, правила архива (P3-A: архивная/пустая сфера = 100%).
- MINOR/MAJOR-версию менять только по явной просьбе владельца.
- Не пушить самостоятельно — пуш делает владелец.

## 4. Ориентиры в коде (index.html, ~3900 строк)

- `APP_VERSION` — единственная точка бампа (≈ строка 528, раздел «===== App version =====»).
- Разделы скрипта помечены `/* ===== ... ===== */`: Seed, Language, State, Cloud sync, Render, Drag-to-reorder.
- Новые функции-обработчики — в соответствующей секции `attach*Handlers`; новые HTML-блоки — отдельной `*HTML()`-функцией рядом с `render()` (стиль уже применён).
- Если функция удалена/переименована — обновить `EXPORT_SRC` в `tests/helpers.js`, иначе `boot()` упадёт (так задумано).
- Тесты гоняют реальный код из `index.html` через vm: новый идентификатор в тесте обязан существовать в проде; чужие realm-массивы оборачивать в `Array.from()`.
